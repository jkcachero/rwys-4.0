## Preserve the AdKit Broker Contract
AdKit integration is a broker for the documented provider operations and payloads. Do not invent bespoke /api/v1/adkit domain endpoints or replacement request schemas. Preserve the documented AdKit paths and request semantics; clarify RWYS forwarding/authentication before adding routes. AdKit verification must use HTTP/curl against the agreed endpoint, not Tinker as a substitute for an API test.
